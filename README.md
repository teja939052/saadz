# For Sadaa ✦

A mobile-friendly, multilingual birthday surprise built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
```

Deploy the project to Vercel or Netlify using the default Vite settings. The portrait is in `public/sadaa-dot-art.png`.

## Personalize

Edit the `wishes` array and the `personal-note` text in `src/App.jsx`. The greeting languages are examples; check translations with a fluent speaker if exact wording matters.
